# BRAND AND DESIGN DIRECTION

ARCHI DRAFT must visually communicate trust and precision. 

The application should feel:
**Professional • Architectural • Technical • Modern • Premium • Trustworthy • Clean**

## ⚠️ BRAND COLOR DECISION REQUIRED
Do not invent an official brand identity or lock random colors. If official Draughtsman Studio branding information is provided later, use it as the primary reference. Until then, rely on neutral, premium placeholders.

## Design Recommendations

### Typography Direction
- **Technical & Clean:** Use modern, legible sans-serif fonts (e.g., Inter, Roboto, or SF Pro) that look sharp on mobile devices. Data density requires excellent readability.

### Spacing & Grid
- **Structured Grid:** Use a strict 8px or 4px baseline grid to reflect architectural precision.
- **Ample Whitespace:** Prevent cluttered screens by using generous margins and padding.

### Border Radius
- **Subtle Curves:** Avoid overly rounded "playful" corners. Use small border radii (e.g., 4px - 8px) for a sharper, more technical aesthetic.

### Cards & Surfaces
- **Flat & Clean:** Use subtle borders or extremely soft shadows. Avoid heavy elevation or skeuomorphism.

### Buttons
- **Clear Hierarchy:** Distinct primary, secondary, and tertiary button styles.
- **Disabled States:** Clearly indicate when actions (like submitting a project) are blocked due to validation.

### Icons
- **Line/Stroke Icons:** Use consistent weight line icons (e.g., Feather icons or Material Symbols Outlined) that feel like architectural drafting lines.

### Forms
- **Clear Boundaries:** Outline input fields to provide clear boundaries.
- **Inline Validation:** Provide immediate, clear feedback directly below inputs.

### Status Indicators
- Use universally understood semantic colors (subdued versions to remain premium):
  - **Success/Completed:** Soft Green
  - **Warning/Pending:** Amber/Orange
  - **Error/Rejected:** Soft Red
  - **Neutral/Draft:** Grey/Blue
