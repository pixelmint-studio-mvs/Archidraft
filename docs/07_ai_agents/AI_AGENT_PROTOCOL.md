# AI AGENT PROTOCOL

This file is specifically for AI agents working on the ARCHI DRAFT project.

## BEFORE ANY WORK
Every agent must:
1. Read `README.md`
2. Read the relevant architecture documents in this folder.
3. Identify the current phase in `DEVELOPMENT_ROADMAP.md`.
4. Inspect existing files.
5. Understand dependencies.
6. Identify files that will be affected.

## AGENTS MUST NOT
- ❌ Invent new project statuses
- ❌ Rename existing enums
- ❌ Change workflows silently
- ❌ Change roles silently
- ❌ Remove security validation
- ❌ Duplicate data models
- ❌ Create duplicate backend actions
- ❌ Modify unrelated files
- ❌ Assume UI restrictions provide security
- ❌ Replace architecture without approval

## AFTER WORK
Every agent must report in their output summary:
- **Files Created**
- **Files Modified**
- **What Changed**
- **Why It Changed**
- **Architecture Rules Followed**
- **Testing Performed**
- **Known Issues**
- **Recommended Next Step**
